# keybr layout files

Layout files for [keybr](https://www.keybr.com) in its `importKeymap` format.

- `it_dvorak.json`: v1 with a dead key for accents on the Quote key (grave; Shift for acute).
- `it_dvorak_simple.json`: v1 without the dead key.

The public keybr site cannot import custom layouts, so these need a self-hosted keybr. Packaging will
be covered in a later step.
